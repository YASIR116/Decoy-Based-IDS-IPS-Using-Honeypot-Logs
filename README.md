# Honeypot + IDS Project

## Components
- Cowrie SSH/Telnet Honeypot
- Dionaea Malware Honeypot (Docker)
- Suricata Network IDS
- Custom ML-based IDS/IPS with dashboard and blocker

## How to Run
1. Run `train_models.py` to train ML models
2. Run `sudo python main.py` to start the IDS
3. Run `dashboard.py` to view live dashboard
